
# Project Methodology

## 1. Data Preparation
The simulated market transaction dataset is processed using Python and Pandas.

## 2. Treatment and Control Groups
Markets are divided into treated and control groups to compare their performance.

## 3. Synthetic Control Method
A weighted combination of control markets is used to estimate the counterfactual outcome for the treated market.

## 4. Double Machine Learning
Machine learning techniques are used to estimate treatment effects while accounting for other influencing variables.

## 5. Data Visualization
Streamlit is used for interactive analysis, and Power BI is used to visualize market performance.

## 6. Business Objective
The objective is to understand the potential impact of pricing interventions on market revenue.
