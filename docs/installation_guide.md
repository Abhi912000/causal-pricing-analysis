
# Installation and Execution Guide

## Project Requirements
- Python
- Visual Studio Code
- Git
- Power BI Desktop

## Step 1: Open Project Folder

Open the causal_pricing_project_vscode folder in Visual Studio Code.

## Step 2: Create Virtual Environment

python -m venv .venv

## Step 3: Activate Virtual Environment

.\.venv\Scripts\Activate.ps1

## Step 4: Install Dependencies

pip install -r causal_pricing_project/requirements.txt

## Step 5: Run Streamlit Application

python -m streamlit run causal_pricing_project/app.py

## Step 6: Open Power BI Dashboard

Open the following file in Power BI Desktop:

causal_pricing_project/powerbi/Causal_Pricing_Dashboard.pbix
