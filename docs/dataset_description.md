
# Dataset Description

## Dataset Name
market_transactions.csv

## Dataset Type
Simulated Market Transaction Dataset

## Description
This dataset contains weekly market-level information used to analyse pricing interventions.

## Dataset Columns

| Column | Description |
| market | Market identification |
| week | Weekly time period |
| revenue | Revenue generated |
| demand_index | Customer demand indicator |
| competitor_price | Competitor pricing |
| promo_spend | Promotional expenditure |
| treated_market | Treated or control market indicator |
| post | Before or after intervention |
| treatment | Treatment indicator |

## Purpose
The dataset is used to analyse market performance and pricing interventions.
