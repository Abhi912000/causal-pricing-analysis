
# Power BI Dashboard Documentation

## Project Title
Causal Inference and Synthetic Control for Algorithmic Pricing

## Objective
The Power BI dashboard is designed to visualize market revenue and pricing intervention data.

## Data Sources
The dashboard uses the following CSV files:

- market_transactions.csv
- weekly_market_summary.csv
- treatment_summary.csv

## Dashboard Visualizations

1. Revenue comparison across markets.
2. Weekly revenue trends.
3. Treatment versus control market comparison.
4. Before and after intervention comparison.
5. Market filtering using slicers.

## Dashboard File

Causal_Pricing_Dashboard.pbix

Location:
causal_pricing_project/powerbi/

## Business Benefits

The dashboard helps users understand market performance, compare revenue across markets, and explore changes before and after pricing interventions.

Note: Descriptive comparisons alone do not establish causal effects.
