# Causal Inference & Synthetic Control for Algorithmic Pricing

## Project Overview

This project focuses on analysing the potential impact of algorithmic pricing interventions on market revenue using causal inference and machine learning techniques.

Businesses frequently change product prices to improve revenue. However, revenue changes can also be influenced by customer demand, competitor prices and promotional spending.

This project explores how causal inference techniques can help estimate the impact of a pricing intervention rather than relying only on simple revenue comparisons.

## Project Objectives

- Analyse market-level revenue performance.
- Compare treated and control markets.
- Study market performance before and after a pricing intervention.
- Explore Synthetic Control methodology.
- Explore Double Machine Learning for treatment effect estimation.
- Visualize business insights using Streamlit and Power BI.
